# optimizer-showdown

## Overview
This project aims to compare the performance of various optimization algorithms in training a simple neural network on the MNIST dataset. The optimizers compared include:

- **SGD (Stochastic Gradient Descent)**
- **AdaGrad**
- **RMSProp**
- **Adam**
- **AdaDelta**

The project is implemented in two ways:
1. **From Scratch**: Custom implementations of the neural network and optimizers using NumPy.
2. **Using Keras**: Leveraging TensorFlow/Keras to build and train the model with built-in optimizers.
